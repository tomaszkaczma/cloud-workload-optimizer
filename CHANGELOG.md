# Changelog

All notable changes to this project are documented here.

## 1.0.0 — 2026-07-29

- Replaced the archived notebook/MATLAB workflow with an installable Python
  package.
- Preserved the official UCI training and test split.
- Removed standard SMOTE and logarithmic transformations.
- Added schema, duplicate-card and target-semantics validation.
- Added raw and order-invariant engineered feature representations.
- Added Categorical Naïve Bayes and class-weighted Random Forest pipelines.
- Added a deterministic poker-rule classifier as the production benchmark.
- Added balanced accuracy, macro F1, per-class metrics and normalised confusion
  matrices.
- Added an audit command, automated tests and GitHub Actions.
- Added a corrected MATLAB reference implementation.
- Added reproducible benchmark assets and methodology documentation.
